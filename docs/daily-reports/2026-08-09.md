## Problems

- 首次 Android 构建需要自动安装 NDK / CMake，因此首次构建明显较慢。
- `model_viewer_plus` 的移动端 WebView 即使读取本地 asset，也需要本机 loopback HTTP 通道。
- 初次自动化缩放手势没有改变相机距离，需要进一步确认交互是否真正到达 WebView。
- 早期调试 / DevTools 循环中，销毁 WebView 时曾出现孤立的 Chromium renderer `code -1` 终止日志；App 本身没有退出。
- 仓库中存在一份未跟踪且与当前 Day 1 总指令冲突的旧计划文档。

## Solutions

- 等待 NDK / CMake 安装完成后重新构建；后续 debug build 已恢复到约 13 秒。
- 使用 Network Security Config 只允许 `localhost` 和 `127.0.0.1`，没有全局开放 cleartext。
- 通过 WebView DevTools 的可信滚轮事件和相机参数变化，确认缩放功能真实生效。
- 额外执行干净的快速退出与重新进入测试；该日志未复现，App PID 保持不变、Android crash buffer 为空，重新进入仍正常加载。
- 保留旧计划文档原样且不纳入本次提交，继续以当前项目总指令为准。
