## Problems

- 首次 Android 构建需要自动安装 NDK / CMake，因此首次构建明显较慢。
- `model_viewer_plus` 的移动端 WebView 即使读取本地 asset，也需要本机 loopback HTTP 通道。
- 早期调试过程中，销毁 WebView 时曾出现一次 Chromium renderer termination（`code -1`）日志；App 本身没有退出。
- 当前使用临时测试 GLB，正式人物照片及对应 3D 模型尚未替换。

## Solutions

- 等待 NDK / CMake 安装完成后重新构建；后续 Debug APK 已稳定构建成功。
- 使用 Network Security Config 只允许 `localhost` 和 `127.0.0.1`，没有全局开放 cleartext。
- 对 WebView 生命周期额外执行干净的快速退出与重新进入复测；renderer termination 日志未再复现，App PID 保持不变、Android crash buffer 为空。

## Remaining Issues

- Day 1 当前没有阻塞项。
- 早期 Chromium renderer termination 日志在后续干净复测中没有复现；App 无 Crash、无持续白屏，目前不构成阻塞。
- 当前 GLB 仅用于技术验证；正式人物照片和对应 3D 模型后续替换。
